## Неделя 1. Локальный Git

### Что сделал
- git init
- Первый коммит 6850289
- понял три области git: 
	изменения в файле есть, но нет в корзинке "stages"
	посмотреть их: git diff
	-> git add FILE ->
        изменения в файле есть, добавлены в корзинку "stages", приготовлены к comit
	посмотреть их: git diff --staged
	-> git commit -m "remark"->
        изменения в файле есть, добавлены в comit
- git restore FILE - страшная команда, пропал день работы: может откатить все изменения (не попавшие в гит)
  надо делать комиты небольшими шагами, и ВСЕГДА смотреть что удалиться через "git diff"
- git restore --staged FILE - безопасная, просто убрать изменения в FILE из списка приготовленных к комиту
- файл ".gitignore" описывает каталоги и файлы, которые не нужны в гите (временные и прочие)
